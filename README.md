# BESTPRICE — динамический поиск Apple Watch и Dyson

Публичный сайт: https://incomesbook.github.io/deals/

Локальный changedetection.io: http://127.0.0.1:8878/

Локальный предпросмотр: http://127.0.0.1:8890/

## Как данные попадают на сайт

1. Установленный Docker changedetection.io наблюдает конкретные публичные карточки товаров.
2. sync-monitor.mjs на авторизованном компьютере читает локальный REST API. REST-токен только в конфигурации changedetection на D:, не попадает в сайт и Git.
3. В prices.json записываются только публичные URL, название, валюта, цена, статус наличия, ошибка проверки и время, без API-ключей.
4. GitHub Pages — статический HTTPS-хостинг: он не может напрямую читать 127.0.0.1. Существующая GitHub авторизация пользователя используется локальной синхронизацией для публикации снимка. Локальное плановое задание должно запускать экспорт каждый час.
5. Сайт получает prices.json каждые 5 минут, отдельно оценивая возраст снимка и дату отдельной проверки товара. Цены старше четырёх часов, ошибки, USD без курса и распродажные страницы исключаются из рейтинга свежих CAD-наблюдений.

## Методика и ограничения

На сайте показывается цена продавца, а не автоматически «лучшая подтверждённая итоговая цена». Налог HST 13% — только арифметическая оценка без доставки и сборов. Для сравнения обязательны точный SKU/цвет/размер/состояние, настоящий продавец, гарантия в Канаде, возврат, местный самовывоз именно конкретного товара, доставка, FX/импорт, налоги и подтверждённая применимость купонов. Будущий cashback и баллы не вычитаются из суммы сегодня. Рассрочка, подписка и аренда не являются эквивалентами владения.

Сервис MCP_BestPrice v0.5.0 содержит полный расчёт с доказательствами и сравнение финансирования. Данный публичный сайт не может подтвердить оформление корзины автоматически.

## Файлы и команды

- index.html — новая адаптивная страница в стилистике Claude с проверенными статусами.
- archive-2026-11-07.html — побайтовая копия старой страницы с историческими ценами 7 ноября.
- sync-monitor.mjs — безопасный экспорт, параметр --publish публикует выборочные публичные файлы в GitHub.
- prices.json — обезличенный снимок без секретов.
- tests/site-smoke.mjs — тесты безопасности и достоверности.
- bestprice-sync.cmd — локальная обёртка планировщика, не публикуется.
- MAP_BESTPRICE_SITE.md — архитектура, аудит тестов и откат.

Команда тестов: node tests/site-smoke.mjs
Команда обновления: node sync-monitor.mjs
Команда публикации: node sync-monitor.mjs --publish

Для предпросмотра: python -m http.server 8890 --bind 127.0.0.1 --directory <путь к репозиторию>

## Безопасность и rollback

Не публиковать ключи/пароли, не добавлять все локальные файлы в git add -A, не обходить HTTP 403 продавцов. Не подавать заявку на кредит и не покупать товар без согласия. При ошибке API экспорт прекращается и не заменяет последнюю копию нулями. Откат через ChangeGuard backup или git revert.
